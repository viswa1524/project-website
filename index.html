Automation Architecture

GitHub Actions CI/CD Pipeline

Configured in .github/workflows/deploy.yml to provide secure, reproducible, automated publishing.

01

Code Push Trigger

Listens on pushes to main branch and manual workflow_dispatch triggers.

02

Environment Config

Executes on ubuntu-latest with minimal token permissions for pages write and contents read.

03

Artifact Packaging

Packages static assets using actions/upload-pages-artifact@v3 with SHA verification.

04

Pages Deployment

actions/deploy-pages@v4 provisions SSL and deploys immediately to GitHub's global CDN edge.

.github/workflows/deploy.yml
YAML · GitHub Actions 
name: Deploy Project Website to GitHub Pages

on:
  push:
    branches: ["main"]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup GitHub Pages
        uses: actions/configure-pages@v4

      - name: Upload Pages Artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: '.'

      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
